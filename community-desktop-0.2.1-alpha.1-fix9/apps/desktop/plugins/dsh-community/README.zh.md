# dsh-community

[English](README.md) | 中文

## 概述

在桌面应用内浏览深流社区目录、阅读插件说明，并查看安装进度。社区版内置此 bundle，可通过侧栏、应用菜单和 Ctrl+M 打开。免费原生插件无需模型 API Key 或额外下载授权；付费插件按社区账号的解锁状态安装。下载仍需要网络连接和制品完整性校验。安装和账号凭据由 Electron 管理。此私有 bundle 依赖桌面 preload，不会向普通 Web profile 添加市场。

<a id="use-this-package"></a>
## 使用此包

在左上方侧栏选择**插件市场**，入口位于插件与自动化之间。选择后打开市场并高亮对应侧栏行；收起侧栏后仍保留图标和提示。目录支持服务端搜索、分类、运行环境与来源筛选、榜单、场景标签和分页。详情会单独加载完整说明，不使用目录短摘要替代。顶部持续显示登录或账号入口。“深流社区”按钮显示 deepseek.stream，并在桌面社区窗口中打开网站。

“已安装”页可启停可写 bundle，卸载前需要确认。市场自身入口在此页受到保护。安装任务显示进度和失败信息，运行期间可取消，失败或取消后可明确重试。这些操作使用当前桌面 profile。

展开任务的**查看安装日志**，可阅读保存的诊断输出，包括安装阶段、命令、工作目录、进程错误和退出码。面板打开期间会持续更新日志，重启应用后仍可查看。暂停自动滚动可检查较早的输出；反馈安装失败时，可以复制或导出日志。日志保存前会对凭据脱敏。历史记录被截断或日志保存、读取失败时，面板会明确提示。

展开**查看运行日志**，可阅读客户端警告和原始错误，以及来源文件、行号和时间戳。这份独立且长度受限的日志在安装结束、Host 不可用或应用重启后仍可查看，不会把客户端错误归到安装任务上。复制和导出包含已脱敏的保留记录。旧桌面安装包会显示更新提示，不会调用其尚不支持的日志 API。

默认情况下，归档下载的整体期限为十分钟，连接或等待新数据的期限为 45 秒。暂时性下载失败最多尝试三次，两次重试分别等待一秒、两秒；保存的任务日志会标明失败的尝试次数及原因。

使用完整包发行的插件显示**完整包下载**。详情提供社区网站的下载与作者安装说明入口。桌面应用不会下载或执行作者安装脚本。旧安装链接会在下载或调用 AI 适配前明确提示需要手动安装。

从仓库根目录构建模块：

```sh
pnpm --filter @deepseek-ai/dsh-desktop run build:market
```

<a id="understand-the-implementation"></a>
## 理解实现

[bundle 补丁](cordis.patch.yml) 挂载包的 [Host 入口](index.js)，该入口不提供 Host 行为。这个活跃 Loader 插件行使客户端模块可被发现。[客户端入口](src/client/index.ts) 通过可释放的客户端服务注册主面板和侧栏入口。导航请求保留到活跃客户端选中市场后才确认；确认携带对应请求标识，可跨模块重载区分请求。[面板](src/client/CommunitySection.tsx) 从[桌面社区 API](../../src/community-types.ts) 接收不含凭据的记录。桌面构建生成模块加载器工厂，共享应用的 React 实例和 UI 基础组件。

[任务日志面板](src/client/CommunityTaskLogPanel.tsx) 仅在展开时读取长度受限的诊断记录尾部。基于游标的读取会追加实时记录，避免请求重叠。收起面板时释放订阅；重新展开时再次读取已保存的历史记录。复制和导出使用主进程已脱敏的日志，包含可见尾部以外的记录。

<a id="model-experience"></a>
## 模型体验

此 bundle 不添加模型可见的工具或消息。桌面安装服务检查原生包兼容性，并发布供面板展示的任务阶段。普通原生安装不调用模型；需要 AI 适配的插件使用单独配置的模型凭据。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与待办

服务端目录和详情的可用性取决于 deepseek.stream。刷新失败时，离线目录仍可阅读。社区登录不会提供官方 DeepSeek API Key；只有需要 AI 适配的插件才需要单独配置模型凭据。任务结果分别报告环境恢复状态和安装失败。
