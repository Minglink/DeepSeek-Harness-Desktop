# 0.2.1-alpha.1 社区插件市场兼容修订

本目录保留累计社区修改的源码、测试和双语文档供逐文件审阅。完整可构建 monorepo 源码见对应 Release 的 source.tar.gz；根目录既有 0.1.6 封装不能用于构建本次安装包。

当前修订为 `community-market-fix-20261010`，完整版本仍为 `0.2.1-alpha.1`。增加三项修复：旧设置导入保留当前用户显式覆盖、旧原文及独占备份，并使用真实 revision 检查；客户端 RPC 注册使用调用者的活动 WebServer 服务并保留原生命周期及授权边界；桌面压缩器在启动时精确选择 `@aiwayds/dsh-dcp` 时默认关闭，用户后续显式选择仍优先。插件选集变更需重启 Host，不声称动态安装热更新即可改变启动快照。

保留此前登录、注册入口、安装授权、票据、精确发行身份、失败回滚和合法内置依赖校验修复。准备阶段不执行第三方插件代码或安装脚本。旧用户会话、账号、凭据和 profile 不属于本次源码或软件下载记录更新的范围。

实际封装 Host/Office 检查和 25 项第一方隔离用例通过。GUI 全套仍有 30 项失败；已有 Web 构建回放有 124 项失败、484 项待运行。各插件的实际启动、重启、客户端及业务验证范围另见市场记录，不能以这些测试替代真实账号、模型、外部服务或正常桌面界面安装验收。

Windows x64 安装包未签名、保持预发布标记，历史发行和校验记录保留。完整构建与验证范围见 Release 说明。
