# 0.2.1-alpha.1 社区安装修复

此目录保留本次修改的源码、测试和双语文档，供逐文件审阅。完整可构建的 monorepo 源码附在对应 Release 的 source.tar.gz 中；本仓库根目录保留既有 0.1.6 桌面封装，不能用旧根目录构建本次安装包。

本次保留安装前的社区登录要求；登录框提供注册和社区网站入口。修复桌面登录缺少可信 Origin、错误提示混淆，以及市场展示版本和发行包版本不一致时的安装拒绝。官网包仍需符合记录的 SHA-256、字节数、格式、名称和发行版本；付费解锁与票据要求保留。

修复包完整版本仍为 0.2.1-alpha.1，文件名中的修订名用于区分旧安装包。Windows x64 安装包未签名。

构建与验收结果见 Release 说明和校验清单。
